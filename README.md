# 대구지점 학사관리

코리아AI아카데미 대구점의 **학생 관리** 앱입니다. 멘토·팀장이 쓰는 **관리자 화면**과 학생이 본인 정보만 보는 **학생 화면**으로 되어 있어요. 출결과 상담 문의(등록 전)는 그룹웨어에서 관리하므로 이 앱에서는 다루지 않아요.

웹사이트 파일은 모두 `public/` 폴더에 있어요.

**배포 주소**: https://chan63078-dot.github.io/daegu-haksa/admin/
`main` 브랜치에 푸시하면 GitHub Actions가 권한 검증 테스트를 돌리고, 통과하면 `public/` 폴더를 GitHub Pages에 자동 배포합니다. 테스트가 실패하면 배포되지 않아요.

| 주소 | 화면 |
| --- | --- |
| `/admin/` | 관리자 화면 (로그인) |
| `/?t=학생토큰` | 학생 전용 화면 (로그인 없음, 링크로만 열림) |

## 지금 바로 써보기 (데모 모드)

`config.js`의 Supabase 값이 비어 있으면 데모 모드로 동작해요. 예시 데이터가 들어 있고, 바꾼 내용은 그 브라우저에만 저장됩니다.

```
python -m http.server 8765 --directory public
```

브라우저에서 `http://localhost:8765/admin/` 을 열고 사람을 골라 들어가면 권한별로 어떻게 보이는지 확인할 수 있어요.

## 실제 운영으로 바꾸기

1. [Supabase](https://supabase.com)에서 지점 공용 메일로 새 프로젝트를 만듭니다. 지역은 Seoul(ap-northeast-2)을 고르세요.
2. SQL Editor에 `supabase/schema.sql` 전체를 붙여 넣고 실행합니다.
3. 이어서 `supabase/staff.local.sql`(대구지점 팀·직원 명단, 저장소에는 올리지 않는 파일)을 실행합니다.
4. Authentication → Users → Add user 에서 직원마다 같은 이메일로 계정을 만듭니다(Auto Confirm 체크, 임시 비밀번호).
5. Authentication → Providers → Email 에서 "Allow new users to sign up"을 끄세요. 직원 계정은 관리자만 만들 수 있게 합니다.
6. Project Settings → API 의 Project URL과 anon public 키를 `public/config.js`에 넣습니다. **service_role 키는 절대 넣지 마세요.**
7. 바꾼 `config.js`를 커밋·푸시하면 자동으로 배포됩니다. (anon 키는 공개되어도 되는 키이고, 데이터는 DB 권한 규칙이 지켜요.)
8. 이후 직원 추가·수정·삭제는 원장·총괄 계정으로 설정 → 직원에서 합니다. 새 직원은 4번처럼 로그인 계정도 만들어 주고, 삭제한 직원은 로그인 계정도 지워주세요.
9. 설정 → 직원 → "안내 문구"를 눌러 직원에게 보낼 사용 안내를 복사합니다(임시 비밀번호는 따로 전달).
10. 학생 → "엑셀로 등록"에서 양식 파일을 받아 학생을 한꺼번에 등록합니다. 한국어 엑셀에서 저장한 CSV도 그대로 읽어요.

## 직원 계정 관리 기능 설치 (한 번만)

설치하면 원장·총괄이 앱의 **설정 → 직원 → 수정**에서 로그인 계정 만들기 · 비밀번호 재설정 · 계정 삭제를 할 수 있어요. Supabase 관리 화면에 들어갈 필요가 없어집니다.

1. Supabase → 왼쪽 메뉴 **Edge Functions** → **Deploy a new function** → **Via Editor**
2. 함수 이름을 정확히 `staff-admin` 으로 입력
3. 편집기 내용을 모두 지우고 `supabase/functions/staff-admin/index.ts` 내용을 붙여 넣은 뒤 **Deploy function**
4. 배포된 함수의 **Details(설정)** 에서 **Verify JWT with legacy secret**(또는 Enforce JWT verification)을 **끄고** 저장
   - 함수가 안에서 직접 로그인과 원장·총괄 여부를 확인하므로 꺼도 안전해요.

관리자 키(service role)는 Supabase 서버 안에서만 쓰이고 브라우저로 나가지 않아요. 직원 명단에 있는 이메일만 계정을 만들 수 있고, 모든 작업은 수정 이력에 남아요.

## 연습용 데모 모드

주소 끝에 `?demo`를 붙이면(`/admin/?demo`) 실제 DB 대신 예시 데이터로 열려요. 직원 교육이나 기능 시험에 쓰세요. 실제 데이터에는 영향이 없어요.

## 권한 검증 테스트

데이터베이스 권한 규칙(`supabase/schema.sql`)을 로컬 Postgres로 검증합니다. 스크립트를 고친 뒤에는 꼭 다시 돌리세요.

```
npm install
npm test
```

멘토·팀장·원장별 읽기/쓰기 범위, 퇴사자·미등록 계정 차단, 학생 링크에 연락처·상담 기록이 안 나오는지, 신청 폼 도배 방지, 앱과 같은 upsert 저장 방식 등 50여 가지를 확인합니다.

## 권한

| 권한 | 볼 수 있는 학생 | 할 수 있는 일 |
| --- | --- | --- |
| 멘토 | 내 담당 학생 | 학생 정보, 상담 기록, 면담, 할 일, 자격증, 취업 기록 |
| 팀장 | 우리 팀 학생 전체 | 멘토 권한 + 담당 변경, 수업·시험 관리, 학생 삭제 |
| 원장·총괄 | 지점 전체 | 팀장 권한 + 팀·직원 관리, 수정 이력, 백업 불러오기 |

권한은 화면뿐 아니라 데이터베이스(RLS)에서도 막혀 있어요.

## 부산 서면점 앱과 다른 점

- 화면 디자인 전체 (상단 메뉴, 따뜻한 종이 톤, 모바일 대응)
- 취업·진학 상세 기록 (회사, 직무, 입사일, 고용보험, 고용 형태)
- 수정 이력 (누가 언제 무엇을 바꿨는지)
- 백업 파일 받기·불러오기
- 다음 기수 연결: 종강 무렵 다음 기수(번호 +1)로 학생을 한 번에 연결
- 시험 접수 마감 3일 전 알림, 수업 시간표(강의실 × 시간) 보기
- 학생 화면에서 학생이 할 일을 직접 체크
- 엑셀(CSV)로 학생 일괄 등록, 직원 사용 안내 문구 복사
- 휴대폰 홈 화면에 앱처럼 추가

## 운영 수칙

- 백업은 주 1회 설정 → 백업에서 받아 공용 드라이브에 보관 (7일이 지나면 원장·총괄 대시보드에 알림)
- 퇴사자는 당일 설정 → 직원에서 "퇴사·비활성" 체크
- 수료한 학생은 학생 링크 탭에서 새 링크를 만들어 이전 링크 막기
- 시험 일정의 예시 데이터는 Q-Net 등에서 실제 일정을 확인해 수정
